**Why this is a standing order.** `wordpress-importer` `v0.13.0` shipped `UAMS-Web/wordpress-importer#494`, which stopped the importer trusting `data-set-*` markup from untrusted post HTML. `tests/Unit/WordPressImport/BardParserSetAttributePassthroughTest.php` asserted that passthrough as today's behavior and said outright in its docblock that it was built to be flipped. The moment `UAMS-Web/uams-statamic-archive#2025` bumped the pin to `^0.13`, five assertions inverted and blocked the gate — `scripts/local-ci.mjs` runs `tests/Unit`. The flip that fixed them had been written weeks earlier and could not merge, because the new assertions need `SetMarkupNonce`, which the then-current `^0.10` pin could not reach. `UAMS-Web/uams-statamic-archive#2025`'s "Known-red before you start" was derived from `v0.13.0`'s release notes, and those notes had no way to know a consumer held a test asserting the old behavior. The cost was low only because one person held both threads.
