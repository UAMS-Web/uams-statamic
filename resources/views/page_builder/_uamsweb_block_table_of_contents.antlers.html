{{# @name UAMS Table of Contents @desc The UAMS Table of Contents page builder block (UAMS-Web/uams-statamic-archive#1283). Lists the page's h2 and h3 headings as jump links. The block renders its own
rather than wrapping the shared `page_builder/uamsweb_block` partial, the way `uamsweb_block_link_list` renders its own component. Two reasons, and the first is an acceptance criterion: the block must disappear entirely when the page has no qualifying headings, so `hidden` has to sit on the OUTERMOST element — hiding an inner list would still leave a padded section and a heading on the page. The shared wrapper passes through no `hidden` and no data attribute, and teaching it to would change a partial 27 other blocks render through. The list is built by `resources/js/toc-engine.js`, which scans the rendered DOM and reveals this nav only once it has headings. It also assigns the anchor ids, reusing any id a heading already has — including the `module--title` id that `components/block_header` puts on every block
