{{# Map viewer — renders a stored `gps` coordinate ({ lat, lng, zoom }) as an interactive Leaflet map with a marker at the coordinate, framed at the stored zoom. Reusable and purpose-neutral: it renders a map of a point and nothing about *why* you're looking at it. Any purpose-specific affordance (a "Get Directions" button on a location page, a "view larger" link, etc.) is the consumer's responsibility, because only the consumer knows the map's intent. Consumers: the location entry page (UAMS-Web/uams-statamic-archive#575) and the page-builder / Bard map sets (UAMS-Web/uams-statamic-archive#987 / UAMS-Web/uams-statamic-archive#988). The tile provider, attribution, max zoom, and default zoom come from the `viewer` section of config/maps.php (env-swappable: OpenStreetMap by default, or any keyed / self-hosted provider). When no provider tile URL is configured, the partial renders nothing. A null / empty coordinate also renders nothing.
