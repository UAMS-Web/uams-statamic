Every value is emitted through `to_json`, so quotes and newlines in author content can never break the script or inject markup. `embedUrl` is emitted only when `url` has a value, the same way `transcript` already is. `to_json` cannot carry an absent value on its own: a modifier chain short-circuits on a null rather than running, so `{{ url | to_json }}` renders nothing at all and would leave `"embedUrl": ` — a syntax error that costs the whole block, not one field. `url` is `required` in all three video sets, so this is a guard against hand-edited or imported data rather than anything the CP can save, and a VideoObject with no `embedUrl` is invalid structured data anyway — better to omit the key than to assert an empty one.
