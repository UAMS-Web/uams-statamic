Most of the site's design records live in the repository, beside the code they describe, rather than in this wiki. This page says where.

| Where | What it holds |
| --- | --- |
| [`docs/DECISIONS.md`](https://github.com/UAMS-Web/uams-statamic/blob/main/docs/DECISIONS.md) | The decision log: every closed design decision, oldest first, with its reasons and the alternatives it rejected. Read it before reopening a question. |
| [`docs/runbooks/`](https://github.com/UAMS-Web/uams-statamic/tree/main/docs/runbooks) | Step-by-step procedures, among them the branch protection on `main`, the production queue, and the stale Vite cache fix. |
| [`docs/specs/`](https://github.com/UAMS-Web/uams-statamic/tree/main/docs/specs) | Specifications for individual features, such as the syndication feed output and the Health Talk podcast. |
| [`docs/schema/`](https://github.com/UAMS-Web/uams-statamic/tree/main/docs/schema) | How the site emits schema.org structured data. |
| `docs/input_*.md` | The migration specifications for content coming from the WordPress site, one file per area (people, Find a Doctor, pages and posts, redirects and others). |
| [`docs/assets-metadata.md`](https://github.com/UAMS-Web/uams-statamic/blob/main/docs/assets-metadata.md) | How asset metadata is stored in SQLite and mirrored to YAML, its sync commands, and deploy notes. |
| [`docs/accessibility/`](https://github.com/UAMS-Web/uams-statamic/tree/main/docs/accessibility), [`docs/editorial/`](https://github.com/UAMS-Web/uams-statamic/tree/main/docs/editorial), [`docs/forms/`](https://github.com/UAMS-Web/uams-statamic/tree/main/docs/forms) | Accessibility, editorial and form notes. |
| [`CONTRIBUTING.md`](https://github.com/UAMS-Web/uams-statamic/blob/main/CONTRIBUTING.md) | The path from an issue to a merged pull request. |
| [`patches/README.md`](https://github.com/UAMS-Web/uams-statamic/blob/main/patches/README.md) | The vendor patches applied through Composer. |
